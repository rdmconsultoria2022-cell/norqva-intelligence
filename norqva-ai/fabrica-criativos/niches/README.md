# niches/ — a biblioteca de nichos

Cada arquivo aqui é a "memória" de um nicho: `<nicho>.md`, no formato de
`../templates/NICHE-template.md`.

- A skill CONSULTA esta pasta antes de raspar: se o nicho já existe, ela parte do doc
  (mais rápido e mais barato).
- Quando a skill analisa um nicho novo, ela CRIA o doc aqui automaticamente.
- Você pode adicionar docs prontos de nichos (packs) — basta soltar o `.md` aqui.

*Esta pasta começa vazia de propósito: a skill funciona pra QUALQUER nicho a partir de
uma URL da Biblioteca de Anúncios.*
